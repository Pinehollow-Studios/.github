# Security policy

Pinehollow Studios builds [Vestige Golf](https://vestige.golf). If you find a
security problem in any of our repositories, in the iOS app, on vestige.golf,
or on pinehollow.studio, please tell us privately first.

## How to report

- Email **support@pinehollow.studio** with "Security" in the subject line.
- Say what you found, which repository, app or site it affects, and how to
  reproduce it. A proof of concept helps; exploiting real accounts does not.
- Please do not open a public issue, pull request or discussion for it. The
  app holds real people's data, and a public report can put that at risk
  before we can fix it.

We will reply as soon as we can, keep you informed while we work on it, and
tell you when it is fixed. We do not run a bounty programme.

## Scope

The current TestFlight build of the app, the `main` branch of each repository,
and the live sites. Each repository may carry its own `SECURITY.md` with more
detail about its security model; this file is the org-wide default.
